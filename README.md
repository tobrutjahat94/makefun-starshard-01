STARSHARD — a top-down arena shooter in a shattered asteroid belt. Pilot the salvage skiff Kestrel through 10 waves of void-drones, draft an upgrade after every cleared wave, and break the Warden, the three-phase boss that ends the run. No libraries, no network: plain ES modules on a 2D canvas, synthesized WebAudio sound, and a seeded world so every screenshot scene replays exactly.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to move, mouse to aim, hold click to fire, SPACE to dash, P to pause.
